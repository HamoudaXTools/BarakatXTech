# BarakatXTech
موقع عربي متجاوب لشروحات صيانة الهواتف واستعادة الوصول بأمان.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا باسم `barakatxtech.github.io` (إذا كان اسم حساب GitHub هو `barakatxtech`) أو أي مستودع عادي.
2. ارفع `index.html` إلى جذر المستودع.
3. من Settings → Pages اختر النشر من الفرع `main` ومجلد `/root`.
4. عدّل بريد التواصل في `index.html` قبل النشر.

ملاحظة: محتوى استعادة الوصول توعوي، ولا يضمن فتح كل جهاز بدون فقدان البيانات.
